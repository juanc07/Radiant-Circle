# Phase 13D.3 — Chat avatar visibility

- Shows the Circle member avatar in the active chat top app bar.
- Shows the other member avatar beside incoming message bubbles.
- Consecutive incoming messages reserve alignment space and show the avatar only on the final bubble in that group, similar to modern messaging apps.
- Outgoing messages remain right-aligned without repeating the sender avatar.
- No chat persistence or Firestore schema changes are required.
