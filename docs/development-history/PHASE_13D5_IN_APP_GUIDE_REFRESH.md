# Phase 13D.5 — In-App Guide Refresh

Updates the player-facing Guide tab so it reflects the current Radiant Circle product instead of the older pre-social flow.

The Guide now covers:
- durable Radiant Circle identity / Google account protection,
- Daily Radiance and Daily Plan,
- Shake to Discover privacy behavior,
- Shared Sparks and accepted Circle connections,
- private mutual-friend chat and safety controls,
- Radiant Rush + score capsules + 12-item Radiant Vault,
- optional Solana wallet / SKR Passport / Ranked Cup wallet behavior,
- Badges, Ranks, streaks and collection progression.

No backend, Firestore, reward, wallet, or chat behavior changes are included in this patch.
