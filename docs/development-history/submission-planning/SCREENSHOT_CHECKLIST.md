# Radiant Rush — Screenshot Checklist

Use this checklist for hackathon submission images, GitHub README images, and demo video planning.

## Required screenshots

Take screenshots of:

1. Welcome screen.
2. Home screen before quests are done.
3. Wallet connected state.
4. Quests screen with action buttons.
5. Sign Daily Proof completed.
6. Send Memo Proof completed.
7. SKR Passport scan result.
8. Profile screen with wallet/proof/SKR summary.
9. Demo tab walkthrough.
10. Leaderboard or badges screen.

## Optional screenshots

- Phantom wallet approval screen for connection.
- Phantom sign message approval.
- Phantom transaction approval.
- Explorer transaction page for memo proof.
- Firebase/Firestore proof data during internal testing only.

## Screenshot safety rules

Do not show:

- Private keys.
- Seed phrases.
- Personal wallet balances not intended for demo.
- Personal Firebase config.
- `google-services.json`.
- Internal API keys or signing credentials.

Safe to show:

- Public wallet address.
- Public transaction signature.
- Public explorer URL.
- Test/devnet memo proof.
- Demo SKR tier.

## Visual quality checklist

- Text is not clipped.
- Buttons are readable.
- No ellipsis on important labels.
- Phone status bar does not cover app title.
- Portrait recording is stable.
- Dark mode or chosen theme looks consistent.
- Network is stable before recording.
